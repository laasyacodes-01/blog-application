# 📝 My Blog - Full Stack Blog Application

A full-stack Blog Application developed as a learning project using HTML, CSS, JavaScript, Node.js, Express.js, Supabase, and JWT authentication.

## 🚀 Features

- User registration and login
- JWT-based authentication
- Protected dashboard
- User-specific blogs
- Create blog posts
- View individual blog posts
- Edit blog posts
- Delete blog posts
- User profile
- Logout functionality
- Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- JWT
- bcryptjs

### Database
- Supabase

### Tools
- Visual Studio Code
- Git
- GitHub
